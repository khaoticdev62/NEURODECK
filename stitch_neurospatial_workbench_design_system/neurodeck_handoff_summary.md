# NEURODECK: NeuroSpatial Workbench — Project Handoff Documentation

## 1. System Overview
NEURODECK is a high-fidelity, technical operating system concept designed for next-generation spatial AI hardware, optimized for a **1280x800** handheld form factor (Steam Deck). The system bridges the gap between low-level system control and high-level AI orchestration, providing a "Workbench" environment for developers and AI researchers.

## 3. Core Functional Suites
The OS is organized into six primary modules:
1.  **Core OS & Initialization:** Hardware scanning, model discovery, and privacy sovereignty setup.
2.  **Dev Tools & Terminal:** Multi-session shell, full IDE workspace with Git diff support.
3.  **AI Orchestration:** Agent team monitoring, configuration, and VRAM-optimized model management.
4.  **Hermes Automation:** Lua-based extension dashboard and visual node-flow builder.
5.  **Knowledge & Storage:** Integrated sandboxed browser, fragment manager, and storage explorer.
6.  **System & Session:** Performance diagnostics, audio spectral analysis, and neural growth persistence.
