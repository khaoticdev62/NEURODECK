# The NEURODECK Just Plain English (JPE) Manual

Welcome to NEURODECK. This manual is written in **Just Plain English**. No jargon, no complicated tech terms, and no assumed knowledge. If you're looking for a feature, you're in the right place.

NEURODECK is an all-in-one smart command center. Think of it like a Swiss Army knife where the knife can talk to you and do your chores. Here is what every tool in the box does and how to use it.

---

## 1. 💬 Chat
**What it is:** The main way you talk to your AI. It’s exactly like texting a very smart friend.
**How to use it:** Type in the box at the bottom and hit Enter. 
- **Voice:** Click the microphone icon to talk out loud instead of typing.
- **Personalities (Personas):** You can change who the AI pretends to be. Type `/john` to talk to a Product Manager, or `/amelia` to talk to a Software Engineer.
- **Commands:** Type `/clear` to wipe the screen and start fresh.

## 2. 🎨 Canvas
**What it is:** A live scratchpad for building things. If you ask the AI to build a mini-website or a calculator, it will draw it here.
**How to use it:** When the AI writes visual code (like HTML or CSS), it pops up in the Canvas. You can tweak the code on the left side, and immediately see the results on the right side.
- **Collaborate:** Click "Host" to share your screen with a friend on the same Wi-Fi.

## 3. 💻 Terminal
**What it is:** A direct line to your computer's inner workings. It's the classic "hacker screen" where you type text commands to make the computer do things.
**How to use it:** Type a command like `dir` (on Windows) or `ls` (on Linux) to see your files. 
- **AI Autocomplete:** Start typing, and the AI will try to finish your sentence. Press `Tab` to accept its suggestion.

## 4. 🔑 SSH
**What it is:** A secure remote control. It lets you type commands on *another* computer from *this* computer.
**How to use it:** Click "New Profile" and type in the address and password of the computer you want to connect to. Click Connect, and you're suddenly controlling that machine from afar.

## 5. 🔗 Tunnel
**What it is:** A magical bridge specifically for the Steam Deck.
**How to use it:** The Steam Deck has two modes (Game Mode and Desktop Mode) that usually can't talk to each other. The Tunnel builds a hidden bridge so you can run NEURODECK in Game Mode but still do heavy lifting in Desktop Mode.

## 6. 📤 Share
**What it is:** A way to beam files to phones, laptops, or other Steam Decks over your home Wi-Fi. No cables needed.
**How to use it:** Pick a file, look for the other device in the list, and hit send. The other person clicks "Accept" to catch the file.
- **Group Code:** Think of this as a shared password. Both devices need the same Group Code (like `NEURODECK`) to see each other.

## 7. 🌐 Browser
**What it is:** A built-in web browser, just like Chrome or Safari, so you never have to leave the app to Google something.
**How to use it:** Click the speed-dial buttons for quick links, or type a web address in the top bar. You can use keyboard shortcuts like `Alt+Left Arrow` to go back.

## 8. 🤖 Agent
**What it is:** A robotic assistant that does complex, multi-step chores for you while you watch.
**How to use it:** Tell it a big task, like *"Find all the duplicate photos in my Downloads folder and delete them."* It will write code, run it, check its own work, and finish the job without you lifting a finger.

## 9. 🧠 Memory
**What it is:** The AI's brain. It remembers important facts about you so you don't have to repeat yourself.
**How to use it:** As you chat, the AI automatically saves useful tidbits here. You can search your memories, delete ones you don't want it to know, or "Pin" important facts so the AI *never* forgets them.
- **Filters:** Easily sort your memories by clicking the filter buttons at the top to only show facts from "Chat", "Docs", or "Games".

## 10. 📝 Prompt Lab
**What it is:** A workshop to help you write better questions for the AI. Better questions get much better answers.
**How to use it:** Type your basic idea, pick a formula (like AIDA for sales writing, or Chain-of-Thought for math), and the Lab will perfectly format your question. 
- **JPE Explanation:** Click this button, and the AI will explain to you—in plain English—why the new prompt is better.

## 11. 🖥️ Remote
**What it is:** A feature that turns your smartphone into a remote control for NEURODECK.
**How to use it:** Start the server on this tab. A QR code will appear. Scan it with your phone's camera, and suddenly you can control NEURODECK directly from your phone screen.

## 12. 📚 Docs
**What it is:** Your personal, searchable library. You can point it at a folder full of text or code, and it will read all of it.
**How to use it:** Click "Index Folder" and pick a folder on your computer. Once it's done reading, you can use the search bar to instantly find answers buried deep inside those files.

## 13. 🌿 Git
**What it is:** A time machine for your code. It tracks every change you make so you can always go backwards if you break something.
**How to use it:** Use this tab to see what files you've changed, save those changes (called a "commit"), or push them to the internet (like GitHub).

## 14. 🧪 API Lab
**What it is:** A testing ground for talking to internet services (APIs).
**How to use it:** If you want to pull weather data or stock prices from a website's API, you can type the address here and see exactly what raw data the website sends back.

## 15. ⚡ CLI Maker
**What it is:** A tool to turn quick ideas into permanent commands you can use forever.
**How to use it:** (Command Line Interface Maker) Write a small script, give it a name, and save it. Now, whenever you type that name in the Terminal, your custom script will run.

## 16. 🕸️ Graph
**What it is:** A visual map of how things connect to each other.
**How to use it:** It draws a web of circles and lines showing how your files, ideas, or projects are linked together. It’s perfect for seeing the "big picture."

## 17. ⏰ Scheduler
**What it is:** An alarm clock for chores.
**How to use it:** Tell NEURODECK to run a specific task or script at a certain time. For example, "Every Friday at 5 PM, backup my files."

## 18. 🔀 Flow
**What it is:** A visual workflow builder. Think of it like connecting digital Lego bricks.
**How to use it:** Instead of writing code, you drag and drop boxes on the screen and draw lines between them to build a chain of events. 

## 19. 💻 IDE
**What it is:** A mini code editor built straight into NEURODECK.
**How to use it:** (Integrated Development Environment) You get a list of your files on the left and a big text editor on the right. Use this when you want to write or edit real code files manually without relying on the AI.
- **Smart Autocomplete:** As you type, the IDE will suggest code completions (just like a real professional editor) and show helpful tooltips when you hover over code.

## 20. ⚙️ Settings
**What it is:** The control panel where you tweak how the app looks and how its brain works.
**How to use it:** Click the gear icon in the top right. Here you can change the app's colors, switch the AI from Google Gemini to a private local model (Ollama), or update your passwords.

## 21. 🧩 Plugins Marketplace
**What it is:** An app store for community-made superpowers.
**How to use it:** Inside Settings, go to the Plugins tab. You can browse and download tiny scripts written by other people that give NEURODECK brand new slash commands or abilities.

## 22. 📋 Prompt Sidebar (Ctrl+P)
**What it is:** A hidden drawer full of smart, ready-to-use AI prompts that change depending on what you're doing.
**How to use it:** Press `Ctrl+P` on your keyboard. A panel slides out from the side offering prompt templates tailored specifically to the screen you are currently looking at.

## 23. 🎮 DeckCode
**What it is:** A translator that turns your gamepad buttons into real software actions.
**How to use it:** Pick up a gamepad (like an Xbox controller or Steam Deck). Pressing a button—or holding it, or double-tapping it—can instantly open a terminal, trigger a macro, or send a prompt to the AI. It runs quietly in the background!
