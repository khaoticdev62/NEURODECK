# Future Roadmap

This document outlines the future phases of the NEURODECK project.

## Phase 2: Extensibility & Memory

- **Plugin System**: Allow users to add custom commands and features via plugins.
- **Lua Automation**: Support Lua scripting for automating terminal tasks.
- **Local Vector Memory**: Implement a local vector database for long-term memory and RAG.

## Phase 3: Collaboration & Advanced Voice

- **Multi-Agent Workflows**: Allow multiple AI agents with different personas to interact.
- **Voice Input (STT)**: Dictation support (Basic version implemented in Story 6.5!).
- **Multiplayer Terminal Collaboration**: Shared terminal sessions with AI assistance.

## Phase 4: Autonomous Systems

- **Custom Scripting Runtime**: Deeper integration with scripting languages.
- **Embedded Shell Integration**: Run a real shell inside the TUI.
- **Autonomous Coding Agents**: AI agents that can write and modify code autonomously.
