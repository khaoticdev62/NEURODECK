# Steam Input Mapping Specification for NEURODECK

This document lists the recommended Steam Input mappings for operating the NEURODECK terminal on a Steam Deck.

## Mapping Table

| Steam Deck Control | Keyboard Mapping | Action |
|---|---|---|
| A | Enter | Submit |
| B | Esc | Cancel / Quit |
| X | Backspace | Delete |
| Y | Space | Insert space |
| L1 | Tab | Focus switch |
| R1 | Shift+Tab | Reverse focus |
| L2 | Ctrl+U | Clear line |
| R2 | Ctrl+V | Paste |
| L4 | Ctrl+P | Cycle persona |
| R4 | Ctrl+R | Regenerate |
| L5 | Ctrl+S | Save session |
| R5 | Ctrl+N | New thread |

## How to Apply

1. Add `neurodeck` (or the launch script) as a non-Steam game in Desktop Mode.
2. Return to Gaming Mode.
3. Open Controller Settings for NEURODECK.
4. Edit layout to match the keyboard mappings listed above.
5. Save as a community layout or local profile.
