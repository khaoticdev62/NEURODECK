# Roadmap Alignment

This note maps the uploaded roadmap PDF to the current `S-Term` / `NEURODECK` codebase.

## Already represented in code

- Conversational assistant shell with multi-pane workspace
- Prompt Lab for structured prompt construction
- Agent switching and local model/provider configuration
- Memory, docs search, browser, share, tunnel, SSH, terminal, and remote views
- Security hardening around rendered HTML and release gating
- E2E smoke coverage for shell behavior
- Command palette for fast navigation and settings access

## Highest-value remaining roadmap slices

1. Provenance and attribution for assistant outputs
2. Guided onboarding and trust/safety explanations
3. A stronger privacy and permissions center
4. Better research/browser citation surfaces
5. Accessibility and keyboard-first refinements across modal flows

## Implementation rule

Keep the next work item small, testable, and tied to a visible user workflow. Prefer one shell-level improvement at a time over broad framework churn.
