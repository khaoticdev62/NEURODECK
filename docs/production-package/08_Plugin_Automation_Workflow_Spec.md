# Automation, Agents, Workflows & Plugin Platform

## Agents
Safe local agents operate with visible plans, approvals, audit logs, cancellation, and strict permission checks.

## Workflows
Workflows are repeatable local runbooks with sequential steps, approvals, pause/resume, cancellation, and run history.

## Permissions
Central capability registry controls privileged access. Unknown capabilities deny by default.

## Plugins
Plugins use a manifest, declared permissions, sandboxed SDK APIs, audit logs, lifecycle controls, and QA gates.
