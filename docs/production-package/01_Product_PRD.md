# NEURODECK Production PRD

## Objective

Build a professional-grade AI workstation that runs local-first, works beautifully on Steam Deck, supports persistent AI sessions, protected memory, project knowledge spaces, context packs, universal search, research workflows, safe automation, and plugin extensibility.

## Users

- Solo developers
- Steam Deck power users
- AI-assisted builders
- Security learners
- Researchers
- Writers
- Modders
- Local LLM users
- Privacy-conscious users

## Core Jobs To Be Done

1. Chat with local and remote AI models.
2. Save and reload conversations.
3. Store reusable project knowledge.
4. Build prompt context intentionally.
5. Search across local workspace data.
6. Protect private and sensitive memory.
7. Organize research findings.
8. Export and import project knowledge.
9. Run safe local workflows.
10. Extend the app through permissioned plugins.

## Product Pillars

- Local-first ownership
- Controller-first UX
- Steam Deck excellence
- Explicit context control
- Privacy-by-default
- Safe automation
- Extensible but sandboxed
- Production recovery
