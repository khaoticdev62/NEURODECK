# NEURODECK Default Controller Map

NEURODECK treats controller input as semantic app actions instead of raw button numbers.

## Steam Deck

| Control | Default action |
| --- | --- |
| `A` | Confirm / activate |
| `B` | Back / cancel / close |
| `X` | Reload / secondary action |
| `Y` | Search / focus input |
| `LB` / `RB` | Previous / next section |
| `LT` / `RT` | Page up / page down |
| `D-Pad` | Directional focus |
| `Left stick` | Directional focus with deadzone |
| `Right stick` | Reserved for future page-mode browser steering |
| `Start` | Main menu |
| `Select` | Controller help |
| `L5` | Save / favorite in context |
| `R4` | Regenerate / reload in context |
| `R5` | New tab / new session in context |
