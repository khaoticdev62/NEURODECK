# Volume XV — Future Platform Roadmap & NEURODECK Ecosystem Strategy

## Vision
Build the first controller-first AI workstation optimized for Steam Deck, Windows, Linux, offline AI, local development, and agent-based workflows.

## Eras
Era 1: PromptDrive — prompt creation, execution, agent routing, macros, controller UX.
Era 2: PromptDrive Workstation — project awareness, persistent memory, multi-agent workflows, plugin marketplace, workspace automation.
Era 3: NEURODECK Platform — unified AI operating environment.

## PromptDrive v1.x
Elite prompt workstation with prompt composer, prompt library, agent system, macro engine, controller runtime, memory engine, plugin SDK.

## PromptDrive v2.x
Project-aware AI workstation with project graph, codebase understanding, workspace intelligence, cross-project memory, predictive suggestions.

## Ecosystem
NeuroDeck Core, PromptDrive, NeuroDeck Studio, NeuroDeck Grid, NeuroDeck Agents, NeuroDeck Mobile, NeuroDeck Sync.

## Future Capabilities
Voice interface, collaborative workspaces, cloud sync, mobile companion, Decky integration, marketplace, multi-agent orchestration.

## Offline-First Strategy
Core offline: prompt library, macros, controller runtime, memory engine, workspace. Online optional: marketplace, sync, remote models.

## North Star
A controller-native AI operating environment where users create, code, research, design, document, automate, and collaborate through controllers, agents, memory, automation, and prompt intelligence.
