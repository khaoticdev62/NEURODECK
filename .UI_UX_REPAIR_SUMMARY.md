## Key Finding: `data-testid` Architecture

**Discovery**: `App.tsx`'s `renderView()` function (lines 924–935) already injects `data-testid="view-{id}"` on the outer wrapper for every one of the 42 views. View component files must NOT add their own testids — doing so creates duplicate testid matches that break Playwright strict-mode selectors.

```tsx
// App.tsx — authoritative testid source
const renderView = (id: ViewId, content: ReactNode) => (
  <div
    id={`view-${id}`}
    data-testid={`view-${id}`}  // ← this is the canonical testid
    ...
  >
    {content}
  </div>
);
```

All 6 views that had inner-root testids were cleaned up in this sprint.
