## Fixed This Sprint

### F-001 — Dead `data-testid` attributes on view component roots

**Severity:** Medium  
**Files:** `ExportsView.tsx`, `MaintenanceView.tsx`, `OrchestratorView.tsx`, `RecoveryView.tsx`, `SecurityView.tsx`, `SyncView.tsx`  
**Issue:** 6 view components had `data-testid="*-view"` on their inner root element. `App.tsx`'s `renderView()` already injects `data-testid="view-{id}"` on the outer wrapper, creating a duplicate testid mismatch in strict-mode Playwright.  
**Fix:** Removed all inner-root testid attributes. App.tsx wrapper is now the sole source.  
**Validation:** 289 Playwright tests pass, 0 fail.

### F-004 — `app.css` lacks documentation as legacy token shim

**Severity:** Low (documentation)  
**File:** `frontend/src/app.css`  
**Issue:** The file contains pre-`--nd-*` legacy CSS custom properties with no indication they're a compatibility layer. Developers risk extending the wrong system.  
**Fix:** Added block comment at the top marking the file as a legacy compatibility shim and pointing to `design-system/tokens/tokens.css` as the canonical source.  
**Validation:** CSS builds; no visual regressions.
