# Steam Deck UX & Release Gate

## Primary Target

- Steam Deck LCD/OLED
- 1280x800 viewport
- SteamOS Game Mode
- Controller-first navigation
- Steam keyboard support

## Global Rules

- No horizontal overflow.
- No hover-only actions.
- No mouse-only critical flows.
- No tiny metadata text.
- Prompt console must remain reachable.
- Dialogs must fit viewport.
- B/Escape closes overlays.
- A/Enter confirms.
- D-pad navigates focus.
